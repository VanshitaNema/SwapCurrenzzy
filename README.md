# SwapCurrenzzy - A currency converter

![image](https://user-images.githubusercontent.com/36589853/118485796-7856bf00-b736-11eb-9da0-8e54063d4898.png)

A sleek and interactive currency converter web application. This project allows users to easily calculate exchange rates between different currencies using a vibrant, user-friendly interface.

✨ Features
Currency Calculation: Convert values between different selected currencies using an intuitive calculator interface.

Interactive UI: Features a modern, responsive design with clear dropdown menus for currency selection and a colorful aesthetic.

Lightweight: Runs entirely in the browser as a static web application without the need for a backend server or complex environment setup.

🛠️ Tech Stack
HTML5: Structures the layout and content of the application.

CSS3: Provides the vibrant styling, layout, and responsive design elements.

JavaScript: Handles the conversion logic, user input, and dynamic DOM updates.
